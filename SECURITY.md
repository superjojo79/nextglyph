# Politique de sécurité

## Signaler une vulnérabilité

Ne publiez pas de vulnérabilité dans une issue publique.

Utilisez le [signalement privé de GitHub](https://github.com/superjojo79/nextglyph/security/advisories/new) (onglet **Security** du dépôt, puis **Report a vulnerability**).

Indiquez si possible la version concernée, les étapes pour reproduire le problème et son impact. Vous recevrez une première réponse sous 7 jours.

## Périmètre

Un clavier voit tout ce que l'utilisateur tape. Sont notamment dans le périmètre :

- toute fuite de texte saisi (journaux, fichiers, presse-papiers, réseau) ;
- toute persistance de données saisies dans un champ mot de passe ou code PIN ;
- tout contournement du mode incognito ;
- toute dépendance ou étape de build compromise.
