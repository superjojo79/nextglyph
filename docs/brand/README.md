# Identité visuelle NextGlyph

Logo fourni par Benoit (novembre 2026) : monogramme « ng » suivi d'un curseur, dégradé violet → bleu → cyan
(`#7C3AED`, `#4F7CF7`, `#22D3EE`) sur bleu nuit `#0B1B3A`. Le mot-symbole est en police Outfit (licence SIL OFL 1.1),
converti en tracés : aucune police n'est nécessaire pour afficher les SVG.

| Fichier | Usage |
| --- | --- |
| `nextglyph-icon.svg` | Icône carrée (base de l'icône Play 512 px et de l'icône adaptative `ime/src/main/res`) |
| `nextglyph-icon-mono-{white,black}.svg` | Icône monochrome (icône à thème Android 13+, impressions) |
| `nextglyph-mark.svg` | Monogramme seul, sans fond |
| `nextglyph-horizontal-{fr,en}.svg` | Logo horizontal avec accroche, fond clair |
| `nextglyph-horizontal-{fr,en}-dark.svg` | Logo horizontal avec accroche, fond bleu nuit (bannière, captures, vidéo) |
| `nextglyph-horizontal-{fr,en}-mono-{white,black}.svg` | Logo horizontal monochrome |
| `nextglyph-logo-{fr,en}*.svg` | Logo vertical (monogramme au-dessus du nom et de l'accroche) |
| `nextglyph-banner-suggestions-{fr,en}.svg` | Bannière Play 1024 × 500 (`images/featureGraphic.png` de fastlane) |

L'icône du lanceur (`ic_launcher_foreground.xml`, `ic_launcher_monochrome.xml`) reprend les tracés de
`nextglyph-icon.svg`, réduits pour tenir dans la zone sûre de 66 dp de l'icône adaptative.
